#  Advanced Conveyor Belt: สายพานคัดแยกแร่ขั้นสูง

โรงหลอมได้รับการอัปเกรดสายพานใหม่ แร่ยังคงเข้ามาตามคิว แต่คราวนี้ระบบสายพานสามารถรับแร่ได้ทีละหลายก้อนพร้อมกัน แถมยังมีระบบสลับทิศทางและเครื่องอัปเกรดแร่ด้วย! 

###  มูลค่าแร่ (Ore Values)
| ชนิดแร่ (Ore) | มูลค่า (Value) | การอัปเกรดถัดไป (Upgrade To) |
| :--- | :---: | :--- |
| `Coal` | 10$ | `Iron` |
| `Iron` | 50$ | `Gold` |
| `Gold` | 200$ | `Diamond` |
| `Diamond` | 500$ | `Diamond` *(ระดับสูงสุด)* |

---

##  เงื่อนไขคำสั่ง (Commands)

ในแต่ละรอบระบบจะได้รับคำสั่งการทำงานที่ไม่เหมือนกัน ซึ่งส่งผลต่อแร่บนสายพานและเงินที่ได้ โดยมีเงื่อนไขดังนี้ :

* **`Add [แร่1] [แร่2] ...`** : นำแร่เข้าท้ายคิวสายพาน (สามารถเพิ่มทีละ 1 ก้อน หรือหลายก้อนพร้อมกันโดยคั่นด้วยช่องว่าง)
* **`Smelt [N]`** : โรงหลอมดึงแร่จาก **หัวคิว** จำนวน `N` ชิ้นไปหลอม และได้เงินตามมูลค่ารวมของแร่ *(หากแร่ในคิวมีน้อยกว่า `N` ให้หลอมเท่าที่มี)*
* **`Drop [N]`** : แร่ที่เพิ่งตกลงมา **ท้ายคิว** หล่นหายไปจำนวน `N` ชิ้น *(หากแร่ในคิวมีน้อยกว่า `N` ให้ถือว่าหล่นหายทั้งหมดจนคิวว่าง)*
* **`Reverse`** : ทำให้ทิศทางสายพานกลับด้าน แร่ที่อยู่ท้ายคิวจะกลายมาเป็นหัวคิวแทนทั้งหมด
* **`Upgrade`** : เครื่องเลเซอร์ทำการอัปเกรดแร่ **1 ก้อนแรกสุด (หัวคิว)** ให้กลายเป็นแร่ระดับถัดไป (`Coal` ➔ `Iron` ➔ `Gold` ➔ `Diamond`)

> 📌 **ยกเว้น** 
> * หากเป็นแร่ `Diamond` อยู่แล้วเมื่อโดน `Upgrade` จะไม่เปลี่ยนสภาพ
> * หากคิวว่างให้ข้ามคำสั่ง `Upgrade` ไปเลย

---

## 📥 Input & Output

### **Input**
* `commands` : List ของคำสั่ง (`str`) ทั้งหมดที่ระบบได้รับ

### 🛡️ **ข้อยกเว้น (Exceptions)**
* หาก `commands` เป็น List ว่าง (ไม่มีคำสั่งเลย) ให้คืนค่า `error`

### **Output**
คืนค่าข้อมูล 2 ตัวในรูปแบบ **List** `(total_money, belt_status)`:
* ตัวที่ 1 `total_money` : มูลค่าเงินรวมที่ได้จากการหลอมแร่ (`int`)
* ตัวที่ 2 `belt_status` : ชื่อแร่ที่ยังค้างอยู่บนสายพานเรียงจากหัวไปท้ายคิว คั่นด้วยช่องว่าง (`str`) หากไม่มีแร่เหลือเลยให้คืนค่า `"Empty"`
