# Mining Cart & Wage Calculator
หลังจากขุดแร่มาได้ทั้งวัน พี่ต้องนำแร่ (กิโลกรัม) มาแบ่งใส่รถรางขนาดต่างๆ (1000, 500, 100 และ 50 กิโลกรัม) และคำนวณค่าจ้างให้คนงาน โดยปกติจะได้ค่าจ้าง 5 บาทต่อแร่ 1 กิโลกรัม แต่ถ้าคนงานทำยอดขุดทะลุ 
เป้าหมายรายวัน ที่กำหนดไว้ จะได้ค่าจ้างส่วนที่เกินเป้าหมายในราคา 10 บาทต่อกิโลกรัม พี่อยากให้น้องช่วยเช็คว่าขั้นต่ำต้องใช้รถกี่คัน และคนงานได้ค่าจ้างเท่าไหร่

# Input
  * `ore` น้ำหนักแร่ที่ขุดได้ทั้งหมด 
  * `quota` เป้าหมายรายวันที่ต้องขุดให้ถึง
  ### ยกเว้น 
  * oreเป็น 0 ให้คืนค่า out
  * quotaเป็น 0 ให้คืนค่า error

# Output
  * `car` จำนวนรถที่ใข้ขั้นต่ำ (เศษที่เหลือต่ำกว่า 50 กก. จะถูกทิ้งไว้)
  * `cost` ค่าจ้างคนงาน
