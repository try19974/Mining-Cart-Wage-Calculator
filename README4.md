# ⛏️ The Mystic Mine 
*น้องๆคือนักขุดเหมืองที่ต้องเดินเข้าไปในอุโมงค์เหมืองแร่ลึกลับ บริหารพลังงานให้ดี ใช้ที่ขุดให้คุ้มค่า และเอาชีวิตรอดออกมาพร้อมกับแร่ล้ำค่าให้ได้

## 📝 รายละเอียดโจทย์ (Description)
น้องจะต้องสำรวจอุโมงค์เหมืองแร่ โดยการเดินขุดแร่ไปทีละบล็อก อุปกรณ์ที่ใช้และชนิดของบล็อกจะส่งผลต่อ **พลังงาน (Energy)** และ **เงิน (Coins)** ของคุณต่างกันไป 


## 🪓 ระบบของที่ขุดแร่ (Pickaxes)

| ชนิดที่ขุด (`pickaxe`) | ขุดหิน (`R`) ได้สูงสุด | ผลกระทบพลังงาน (Energy Multiplier) |
| :--- | :---: | :--- |
| `Wood` | 2 ก้อน | ปกติ (x1) |
| `Iron` | 5 ก้อน | ปกติ (x1) |
| `Diamond` | อนันต์ *(ไม่มีวันพัง)* | **หนักมาก!** เสียพลังงาน 2 เท่า (x2) สำหรับบล็อกที่ต้องใช้แรง |

---

## 🧱 ชนิดของบล็อก (Block Types)

| สัญลักษณ์ | ชนิดบล็อก | พลังงานที่เสีย | ผลลัพธ์ / สิ่งที่ได้ (Effect) |
| :---: | :--- | :---: | :--- |
| `D` | **Dirt** (ดิน) | -1 | ไม่มี |
| `R` | **Rock** (หิน) | -2 | ความทนทานที่ขุดแร่ลดลง 1 ก้อน |
| `G` | **Gold** (ทอง) | -1 | ได้เงิน **+50$** |
| `S` | **Silver** (เงิน) | -1 | ได้เงิน **+20$** |
| `C` | **Coal** (ถ่านหิน)| -1 | ได้เงิน **+5$** และ **ฟื้นฟูพลังงาน +5** (หลังจากขุดเสร็จ) |
| `M` | **Monster** (มอนสเตอร์)| **-5** *(ไม่โดนคูณ 2)* | ถูกโจมตี! เสียเงิน **-10$** *(เงินต่ำสุดคือ 0 ติดลบไม่ได้)* |
| `B` | **Bomb** (ระเบิด) | 0 | ระเบิดเปิดทาง ทำให้สามารถเดินข้าม (Skip) บล็อก **1 บล็อกถัดไป** ฟรีๆ (ไม่เกิดผลใดๆ) |

---

## 📜 เงื่อนไขและกฎการสำรวจ (Rules)

1. **การพังของที่ขุด**: หากขุดหิน (`R`) จนครบโควต้า ที่ขุดจะเปลี่ยนสถานะเป็น "พัง" ทันที
2. **ทางตัน**: หากเดินไปเจอหิน (`R`) ในขณะที่ที่ขุดพังไปแล้ว คุณจะไม่สามารถขุดหินก้อนนั้นได้ และ **ต้องหยุดการสำรวจทันที** *(ไม่เสียพลังงานในบล็อกหินที่ขุดไม่ได้)*
3. **เงื่อนไขการหยุดสำรวจ**: การขุดเหมืองจะสิ้นสุดลงทันทีเมื่อเกิดเหตุการณ์ใดเหตุการณ์หนึ่งดังนี้:
   - เดินขุดจนจบ
   - พลังงานเหลือ `0` หรือติดลบ หลังจากทำผลของบล็อกนั้นๆ เสร็จ *(หากติดลบ ให้เซ็ตค่าพลังงานสุดท้ายเป็น `0`)*
   - เจอหินตอนที่ขุดพังไปแล้ว

## 📥 Input & Output

### 🔹 Input
* `mine_path` : แผนผังเหมืองแบบ 1 มิติเรียงจากซ้ายไปขวา (`str`) เช่น `"DDRGCSMBR"`
* `energy` : พลังงานเริ่มต้นที่เป็นค่าบวก (`int`)
* `pickaxe` : ชนิดของที่ขุดแร่ (`str`) มี 3 ค่าคือ `"Wood"`, `"Iron"`, `"Diamond"`
### ยกเว้น
*mine_path เป็นstringเปล่าตั่งแต่เริ่มให้คืนค่า 'error'
*energy เป็น 0 ตั่งแต่เริ่มคืนค่า 'error'

### 🔹 Output
คืนค่าข้อมูล 3 ตัวในรูปแบบ **List** `[total_coins, energy_left, is_broken]`:
1. `total_coins` : จำนวนเงินรวมที่เก็บได้ (`int`)
2. `energy_left` : พลังงานที่เหลืออยู่เมื่อจบการสำรวจ (`int`)
3. `is_broken` : สถานะที่ขุดแร่ว่าพังหรือไม่ (`bool`) *(พังเป็น'True' ไม่พังเป็น'False')*
